# Frontier Command｜前線指揮官 (Grok Improved Edition)

這是從 [jasonchangandsrarhchen/game](https://github.com/jasonchangandsrarhchen/game) 分支出來的改進版本。

原作者做出了非常完整的四國混戰 RTS 原型（單檔 HTML）。本分支在不破壞原有玩法的前提下，進行結構整理、體驗優化與可維護性提升。

## 遊戲簡介

四國自由混戰即時戰略：

- **藍方（玩家）**、紅方、紫方、金方各自從地圖四角出發
- 三個 AI 國家彼此敵對，也會主動發展、爭奪中央資源並發動攻擊
- 消滅其他三國主堡即可獲勝；己方主堡被摧毀則戰敗

### 核心系統

- **文明選擇**：開局可選 4 個文明，各有獨特加成與專屬單位
- **文明科技樹**：每個文明在科技研究所有 4 項專屬科技
- **時代進階**、**世界奇觀**、Fog of War、小地圖等

## 如何遊玩

直接用瀏覽器開啟 `index.html` 即可。

## 版本說明

本 repo 的 `main` 已更新為 **Grok Improved Edition**（含文明科技樹、美術強化、小地圖等）。
